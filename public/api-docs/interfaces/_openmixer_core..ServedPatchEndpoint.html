    Interface ServedPatchEndpoint

    A patch endpoint AS THE CONSOLE SERVES IT: the patch, plus what the live graph says about it right now. At most ONE mark, and absent means every leg is live and carrying audio:

    • deferred — the patch carries NO audio: the source is absent from the live graph (a stopped stream, an unplugged stagebox), or every leg is still waiting on the head input. A surface ghosts the cell.
    • partial — the source is present and at least one leg is live, while another waits on an absent destination: a stereo source running on one leg. Half-connected is a real operating condition and neither alternative tells the truth about it — drawn live it hides a dead leg, ghosted it claims a source that IS feeding the desk is gone.

    SEPARATE from PatchEndpointJson on purpose: that type is what a patch IS — it is persisted, under PATCH_SCHEMA_VERSION — and this is what the patch is DOING. A stored mark would carry one room's absent stagebox into the next room, where the box is plugged in.
