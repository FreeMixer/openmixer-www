    Interface SurfaceHost

    The north-side contract a control surface (a physical MIDI desk like the Behringer X-Touch / a Mackie MCU, an OSC client, or the web UI) binds to. It is exactly the slice of MixerEngine a surface needs: push canonical control intents in (SurfaceHost.setFader …), and subscribe out to canonical state changes (SurfaceHost.subscribe) so motor faders, button LEDs, scribble strips and meters can track the model. The surface never touches a device protocol — it meets every other control source at this canonical boundary.

    This is the ControlSource host promised in adapter.ts's header: a surface adapter depends on this interface, not the concrete engine, so it stays testable against a lightweight fake host.

    Optionalselect

    • select?(channel: ChannelId): Promise<void>

      Select a channel — the console's global SEL (one selected strip per mixer, like a real desk). Optional: a host without shared selection simply omits it, and the surface keeps its selection local (the pre-#97 behaviour). Hosts that implement it fan the change back out as a selection event so every surface's SELECT LEDs and the web-ui's selected strip converge.
